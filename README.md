# 🍸 Cocktail Bar Website

A modern, interactive promotional website for a Cocktail Bar, featuring high-performance scroll animations and a sleek user interface. This project is an adaptation of the "Creative Frontend Course" project, refactored from a standard Vite/React setup into a robust Next.js application with strict TypeScript typing.

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** GSAP (GreenSock Animation Platform) & ScrollTrigger
- **Deployment:** Vercel / Netlify

## ✨ Features

- **Custom GSAP Animations:** Complex timeline sequences and scroll-triggered animations utilizing `@gsap/react`.
- **Server-Side Rendering (SSR) Compatibility:** Architecture split between Server Components for SEO/performance and Client Components (`"use client"`) for DOM-dependent GSAP animations.
- **Fully Responsive:** Fluid layouts built with Tailwind CSS, optimized for both desktop and mobile viewports.
- **Type Safety:** Strict TypeScript interfaces for component props and animation references.

## 🛠️ Getting Started

First, clone the repository and install the dependencies:

```bash
git clone [https://github.com/greg-motion-dev/cocktail-website.git](https://github.com/greg-motion-dev/cocktail-website.git)
cd cocktail-bar
npm install
```
